# 🔐 CipherShield - Text Encryption & Decryption Tool

A simple, modern, and secure web application to encrypt and decrypt text messages using the AES-256 algorithm.

---

## ✨ Features

- 🛡️ **AES-256 Encryption:** High-level security powered by CryptoJS.
- 🔑 **Secret Key Protection:** Uses custom passphrases for encrypting and decrypting.
- 🌙 **Modern Dark UI:** Clean, responsive design that works on mobile and desktop.
- 📋 **Quick Copy:** Easily copy the output result to your clipboard with one click.
- 🔒 **100% Client-Side:** Your messages and keys stay in your browser and are never sent to any server.

---

## 🛠️ Tech Stack

- 🌐 **HTML5** - Application structure
- 🎨 **CSS3** - Modern dark styling and layout
- ⚡ **JavaScript** - Application logic
- 📦 **CryptoJS** - Cryptography library

## 🚀 How to Use

1. Download or clone the repository.
2. Open `index.html` in any web browser.

### 🔒 To Encrypt:
1. Enter your text in the **"Your Message"** field.
2. Enter a secret key in the **"Secret Key"** field.
3. Click **"Encrypt Text"**.

### 🔓 To Decrypt:
1. Paste the encrypted text into the **"Your Message"** field.
2. Enter the **exact same secret key** used during encryption.
3. Click **"Decrypt Text"**.
